# Colorways Themes

Themes inspired by [Firefox Colorways](https://support.mozilla.org/en-US/kb/personalize-firefox-colorways).

Available for [VS Code](https://marketplace.visualstudio.com/items?itemName=Franthormel.colorways)

## Folders

- `/assets`
  - Icon files, to be used amongst the projects
- `/references`
  - Reference guide for the color values
- `/test-files`
  - Sample code files for testing the themes
- `/themes-intellij-idea` (TBD)
  - Project files for IntelliJ IDEA
- `/themes-vscode`
  - Project files for VS Code
